# React Card UI Project

A simple and reusable React Card UI project built using React.js and CSS.  
This project demonstrates component reusability and props handling in React.

---

# 📸 Project Preview

The application displays multiple cards with:

- User Name
- Email Address
- Reusable Button Component

---

# 🚀 Features

✅ Reusable Card Component  
✅ Reusable Button Component  
✅ Props Passing in React  
✅ Simple Responsive UI  
✅ Component-Based Structure  
✅ Beginner Friendly Project

---

# 🛠️ Technologies Used

- React.js
